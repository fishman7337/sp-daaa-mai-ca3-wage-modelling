# Academic Integrity

This repository is organised to make the MS0240 CA3 work reproducible and easier to review. It should not be used to misrepresent authorship or submit work without proper acknowledgement.

## Principles

- Keep Goh Kun Ming as the author of the submitted coursework unless a future version clearly documents additional contributors.
- Cite external data, institutional materials, and references in the report.
- Preserve the distinction between original coursework analysis, derived datasets, and third-party assets.
- Use tests and scripts to check consistency, not to manufacture results that do not match the data.

## Reuse

You may reuse the MIT-licensed code and documentation structure, but you should not copy the coursework report or submit it as someone else's academic work.
