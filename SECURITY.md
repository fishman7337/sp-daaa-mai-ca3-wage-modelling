# Security Policy

This project does not run a public service and should not contain secrets. Treat it as a local coursework and reproducibility repository.

## Supported Scope

Security review applies to:

- Python scripts and package code.
- CI configuration.
- Environment examples and documentation.

It does not apply to third-party source datasets, Singapore Polytechnic assets, or assignment files beyond how this repository references them.

## Reporting

If you find a security issue, remove any exposed secret locally, rotate the credential if relevant, and notify the project owner. Do not open public issues containing credentials, personal data, or exploit details.
