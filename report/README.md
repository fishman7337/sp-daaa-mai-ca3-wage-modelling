# Report

This folder contains the LaTeX source for the MS0240 CA3 report.

## Files

- `main.tex` - report source.
- `references.bib` - bibliography entries.
- `figures/` - report screenshots and regression output images.
- `assets/` - institutional logo asset used on the cover page.

## Build

From the repository root:

```powershell
.\scripts\build_report.ps1
```

The compiled submission PDF is copied to `.dist/submission/MS0240-CA3-Wages-Regression-Report.pdf`.
