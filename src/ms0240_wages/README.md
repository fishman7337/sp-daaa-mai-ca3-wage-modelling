# ms0240_wages

Reusable Python package for the MS0240 CA3 regression analysis.

Main entry points:

- `load_wages_data`
- `load_model3_data`
- `model1_without_intercept`
- `model2_with_intercept`
- `model3_multiple_regression`

The functions intentionally mirror the mathematical setup in the report so that pytest can verify the submitted values.
